# ☁️ Гайд по настройке Cloudflare Worker (Радар Молний)

Этот гайд поможет тебе бесплатно настроить "радар", который будет сканировать датские новости каждые 3 минуты и запускать твоего бота (вне очереди), если найдет СРОЧНУЮ новость.

## Шаг 1: Создание GitHub Token (PAT)
Cloudflare должен иметь право запускать твой GitHub Action.
1. Зайди на GitHub: **Settings** -> **Developer settings** -> **Personal access tokens** -> **Tokens (classic)**.
2. Нажми **Generate new token (classic)**.
3. Введи название (например, `Cloudflare Radar`).
4. Поставь галочку возле `repo` (Full control of private repositories).
5. Нажми **Generate token** и скопируй его. **Он понадобится на следующем шаге.**

## Шаг 2: Регистрация Cloudflare
1. Зайди на [dash.cloudflare.com](https://dash.cloudflare.com/sign-up) и зарегистрируйся (это бесплатно, кредитка не нужна).
2. В левом меню выбери **Workers & Pages**.
3. Нажми синюю кнопку **Create Application**, затем **Create Worker**.
4. В разделе **Select a method** выбери **Start with Hello World!**.
5. Назови воркера `danish-news-radar` и нажми **Deploy**.

## Шаг 3: Вставка кода
1. После деплоя нажми **Edit Code**.
2. Откроется редактор. Удали всё, что там есть.
3. Скопируй весь код из файла `scripts/cloudflare_breaking_worker.js` (который лежит в нашем проекте) и вставь его в редактор Cloudflare.
4. В самом начале кода убедись, что `GITHUB_OWNER` = "твой ник в гитхабе" (например, `deusflow` или `open-gsd`), и если нет, измени его.
5. Нажми синюю кнопку **Save and Deploy** в правом верхнем углу.

## Шаг 4: Безопасное добавление токена (Секреты)
Мы не храним токен в самом коде (это небезопасно).
1. Выйди из редактора кода обратно в настройки Worker'а (`danish-news-radar`).
2. Перейди во вкладку **Settings** -> **Variables and Secrets**.
3. Нажми кнопку **Add** в разделе Secrets (или Variables, выбрав тип Secret).
4. В поле Variable name напиши: `GITHUB_PAT`.
5. В поле Value вставь свой токен (из Шага 1).
6. Нажми **Deploy** (или Save). Теперь скрипт будет безопасно доставать этот токен при работе.

## Шаг 5: Настройка расписания (Крон)
Чтобы скрипт работал сам по себе:
1. Выйди из редактора кода обратно в настройки Worker'а (`danish-news-radar`).
2. Перейди во вкладку **Triggers** (Триггеры).
3. В разделе **Cron Triggers** нажми **Add Cron Trigger**.
4. Выбери интервал (например, каждые 3 минуты) и сохрани.

## Шаг 6: Защита от дубликатов (KV Storage) - Опционально, но желательно
Чтобы бот не отправлял одну и ту же молнию каждые 3 минуты:
1. В левом меню Cloudflare выбери **Storage & databases** -> **KV**.
2. Нажми **Create a namespace**, назови его `DKNEWS_STATE` и нажми Add. *(Вручную никакие Key-Value туда добавлять не нужно! Скрипт сам будет записывать туда ссылки на новости, чтобы не присылать дубли).*
3. Вернись в твой Worker (`danish-news-radar`) и перейди во вкладку **Bindings** в верхнем меню (рядом с Settings).
4. Нажми кнопку **Add binding** и выбери **KV namespace**.
5. Укажи **Variable name (Variable)**: `DKNEWS_STATE` и выбери созданный в выпадающем списке KV-namespace (например, `DKNEWS_STATE`). Сохрани (Deploy).

## Шаг 7: Как проверить работоспособность (Тестирование)
Ты можешь запустить радар вручную прямо сейчас:
1. Открой в браузере адрес своего воркера: `https://danish-news-radar.deuswork.workers.dev` (или скопируй URL со страницы воркера).
2. На экране должно появиться сообщение: `Radar check complete. Found breaking: false` (или `true`, если прямо сейчас в Дании случилось ЧП).
3. **Как посмотреть логи работы:**
   - Зайди в твой Worker -> вкладка **Observability** (или **логи**).
   - Нажми **Begin log stream** (Начать стрим логов).
   - Обнови страницу воркера в браузере.
   - В консоли логов Cloudflare появится лог запроса. Если там нет ошибок подключения к GitHub API (красных строк), значит всё настроено идеально!
